# Skeleton

データの読み込み中に、読み込み後の画面の構造を示す。

| | |
| --- | --- |
| 実装 | [`registry/components/ui/skeleton.tsx`](../../../registry/components/ui/skeleton.tsx) |
| 元にした実装 | shadcn/ui の Skeleton |
| 状態 | 初期実装 |

## 1. Purpose

読み込みを待つ間に、これから何がどこに表示されるかをユーザーが予測できるようにする。

## 2. Usage

- 読み込み後と同じ構造、大きさ、形で並べる。文字は行の高さ、Avatar は円、Badge は Full Radius。
- 短時間（目安 300ms 未満）で終わる読み込みでは、Skeleton を無理に表示しない。
- 表示のために読み込みの時間を延ばさない。
- 読み込みに失敗したら Skeleton を消し、失敗の文と次の操作を表示する。
- 長い待機では、Progress などで実際の処理状況を伝える。

## 3. Anatomy

| 部分 | 値 | トークン |
| --- | --- | --- |
| 面 | ニュートラル | `bg-border` |
| 角丸 | 既定 12px。読み込み後の形に合わせて指定する | `rounded-md` など |
| 動き | 明滅（不透明度 100% ↔ 50%）、1.8 秒周期 | `animate-pulse`、`[animation-duration:1.8s]` |

`muted` は白い背景との差が小さく（1.09:1）、明滅すると見えにくいため、`border`（1.26:1）を使っている。光が流れる Shimmer は使わない。

## 4. Variants

種類はない。形は `className` で読み込み後の要素に合わせる。

## 5. Behavior

- 個々の Skeleton は読み上げない（`aria-hidden`）。
- 読み込み中は、親要素に `aria-busy="true"` を付け、`role="status"` の文字（例：「顧客一覧を読み込んでいます」）で知らせる。これは製品が担う。
- 動きを減らす設定では、明滅を止める。

## 6. Anti-patterns

| 避ける | 理由 | 代わりに |
| --- | --- | --- |
| 読み込み後と関係のない大きな四角 | 切り替わるとレイアウトが動く | 同じ構造にする |
| 失敗しても Skeleton を出し続ける | 待てば表示されると誤解する | 失敗の文と次の操作 |
| 一瞬で終わる読み込みに出す | 画面がちらつく | 出さない |
| Shimmer（光が流れる動き） | 動きが強く、注意を奪う | 控えめな明滅 |
