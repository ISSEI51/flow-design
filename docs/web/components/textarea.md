# Textarea

複数行の文章を入力する。

| | |
| --- | --- |
| 実装 | [`registry/components/ui/textarea.tsx`](../../../registry/components/ui/textarea.tsx) |
| 元にした実装 | shadcn/ui の Textarea |
| 状態 | v0.1 確定 |

## 1. Purpose

ユーザーが、長い文章を見直しながら入力できるようにする。

## 2. Usage

- 備考、問い合わせの内容、理由など、1 行に収まらない文章に使う。
- 想定する文章の長さに合わせて、最初の高さ（`rows`）を決める。
- 文字数の上限がある場合は、入力中に残りの文字数を示す。上限を超えた時点でエラーにする（検証のタイミングの例外）。

## 3. Anatomy

| 部分 | 値 | トークン |
| --- | --- | --- |
| 最小の高さ | 96px | `min-h-24` |
| 余白 | 左右 16px、上下 12px | `px-4 py-3` |
| 文字、角丸、境界線、フォーカス | Input と同じ | Input の `controlClassName` を共有 |
| 大きさの変更 | 縦方向だけ | `resize-y` |
| 高さ | 入力に合わせて広がる | `field-sizing-content` |

## 4. Variants

Input と同じ状態（通常、フォーカス、入力済み、無効、読み取り専用、エラー）を持つ。

## 5. Behavior

- Base UI の Field.Control として `<textarea>` を描画し、Field の中ではラベル、説明、エラーと関連付けられる。
- 横方向の大きさは変えられないため、周りのレイアウトを崩さない。
- `field-sizing: content` に対応しないブラウザでは、`rows` の高さで表示され、縦方向に大きさを変えられる。

## 6. Anti-patterns

| 避ける | 理由 | 代わりに |
| --- | --- | --- |
| 長文の欄を 1 行の高さにする | 書いた内容を見直せない | 文章の長さに合わせた `rows` |
| 横方向の大きさの変更を許す | レイアウトがはみ出す | 縦方向だけにする |
| 文字数の上限を送信時にだけ知らせる | 書き直しの量が増える | 入力中に残りの文字数を示す |
